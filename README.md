#  Age Calculator

A modern and responsive Age Calculator web application built using HTML, CSS, and JavaScript.
This project allows users to calculate their exact age based on their date of birth with a clean, elegant, and user-friendly interface.


## Features

*  Date of birth selection
*  Instant age calculation
*  Modern and responsive UI
*  Mobile-friendly design
*  Accurate chronological age calculation
*  Smooth and clean user experience


# Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
